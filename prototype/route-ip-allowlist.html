IP 白名单

        
非空时仅名单内的来源 IP 可访问该域名；留空表示不限制（默认）。由 WAF 的 IP 阶段执行，命中拦截返回 403。


        

          

            
启用 IP 白名单

            
写入 rules[].waf.allow，并自动补 waf.enabled: true。关闭后该域名恢复为「所有来源可访问」。

          

          
        


        

          
白名单已启用但列表为空：当前不会拦截任何请求。请至少添加一个允许的 IP / CIDR，或关闭白名单。
